# سند | Sanad — الحزمة الجاهزة للنشر

تتضمن هذه الحزمة واجهة ويب عربية متجاوبة لهوية سند المعتمدة، مع الشعار المرفق.

## النشر المجاني عبر GitHub Pages
1. سجّلي الدخول إلى GitHub وأنشئي مستودعًا باسم `sanad-os`.
2. ارفعي الملفات الموجودة في هذه الحزمة إلى جذر المستودع: `index.html` و`sanad-logo.jpg`.
3. افتحي **Settings → Pages**.
4. ضمن **Build and deployment** اختاري **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)` واضغطي **Save**.
5. انتظري حتى يكتمل النشر؛ سيظهر رابط الموقع في صفحة Pages.

## تنبيه مهم
هذه نسخة واجهة تجريبية فقط. وظائف المحادثة والقوائم توضيحية وليست متصلة بذكاء اصطناعي أو قاعدة بيانات أو نظام دخول. لا ترفعي بيانات شخصية أو مستندات قانونية سرية. المستودع العام يجعل الملفات متاحة للعموم. لا تضعي مفاتيح API في ملفات الموقع. قبل الاستخدام الفعلي يلزم بناء خادم آمن، ومصادقة، وسياسات صلاحيات وتخزين، ومراجعة قانونية لمحتوى التشريعات.
